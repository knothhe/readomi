# Readomi 隐私政策中文译文

更新日期：2026 年 10 月 8 日。本译文对应仓库根目录的 `PRIVACY.md`；商店隐私链接指向正式英文政策。两份政策随实现一起更新。

Readomi 支持网页、段落、输入框和已有视频字幕翻译。它没有开发者运营的翻译服务器、账号系统、云同步、分析统计或遥测。开发者不会通过扩展收到你的网页内容、API Key 或浏览历史。

## 发送到你配置的服务的数据

请求从浏览器直接发送至你配置的模型服务或兼容接口。支持 OpenAI、Anthropic、Google Gemini、DeepSeek、兼容网关和本地模型。网关可能按其条款转发请求给上游服务。

翻译请求包含待处理文本、提示词、语言规则和模型参数。网页翻译自动包含可用的页面标题。开启“结合文章上下文”后，还会发送标题和提取正文的前 2,000 个字符生成摘要；正文提取失败时使用页面 body 文本，仍按相同上限截断。默认与自定义提示词附加可用标题及启用后的摘要；自定义提示词也可引用页面描述或截断正文。字幕与输入框翻译使用共用语言规则，不附加网页背景或文章摘要。

源语言在翻译请求内判断，辅以有限的本地结果检查。Readomi 不会在打开页面时单独请求语言识别。整页翻译开启后，同站点导航、新内容或恢复翻译仍可能发起后续请求。“保持原文”不保证该语言的文本绝不发送给服务。

输入框翻译默认开启。在同一已聚焦编辑框连续按三次空格、相邻间隔不超过 300 毫秒时，将框内文本发送给服务。支持文本输入框、textarea 和受支持的富文本编辑器；密码、禁用、只读字段和输入法组合不触发。扩展不逐键上传输入。成功后替换框内文字，不自动提交表单。取消或失焦可阻止旧结果写回，但不能撤回已经发出的请求。

字幕翻译发送已有 YouTube 字幕或 HTML5 字幕文本，不发送视频音频，也不识别无字幕视频的语音。扩展自带的 YouTube 桥接脚本可能携带页面的网站凭证从限定的 YouTube 字幕地址获取字幕；模型 API Key 不传入该桥接流程。

连接检查发送简短翻译请求；模型列表查询配置的服务。适用请求附带 API Key、自定义请求头与请求体参数。自定义请求体可覆盖请求字段。模型服务请求使用 Readomi/<版本> 标识客户端；Chrome 和 Edge 通过动态请求头规则设置扩展自身请求的 User-Agent。服务商还可收到 IP 地址等常规网络信息。

服务商按其政策与条款处理请求，开发者不控制其保留、训练或访问规则。处理敏感内容前请阅读所选服务的政策。官方地址使用 HTTPS；自定义地址可使用 HTTP，包括本地模型接口。远程服务应使用 HTTPS。

## 保存在浏览器中的数据

扩展本地存储保存服务配置、API Key、自定义请求头与请求体、连接检查结果、提示词、语言、外观、开关、停用站点的主机名和站点规则。API Key 不保存在单独加密的密钥保险库中。学得的请求速率与批次限制也保存在本地，读取时过滤超过 90 天未更新的记录。

IndexedDB 缓存译文或保留原文标记、文章摘要、创建时间以及归属主机名或页面 URL 的哈希。网页文字译文可在同一主机名下复用；字幕与摘要按页面保存。超过七天的条目进入清理范围，浏览器可运行扩展时约每天检查一次；关闭或挂起浏览器可能延迟清理。

临时会话存储保存各标签页的翻译与字幕开关、站点范围，以及站点适配的 URL、规则草稿、预览确认和撤销信息；关闭标签页会清理其会话。Readomi 不建立按时间排列的浏览历史，也不向开发者发送这些状态。设置与密钥保留到修改或卸载扩展，不跨设备同步。

## 你主动创建的副本

完整配置备份为本地 JSON 文件，包含设置、API Key、自定义请求头与请求体。服务配置导出及 agent 设置说明只遮蔽专门的 apiKey 字段，不会自动脱敏请求头或请求体。请妥善保管。卸载扩展不会删除导出文件或已经分享的副本。

站点适配说明包含当前完整 URL、你描述的问题、相关规则和阅读设置，不包含服务凭证。Readomi 只生成或复制说明与配置，不自动发给 agent。主动分享给 agent 或其他应用后，接收方按其条款处理。

## 权限与用途

storage 保存配置与阅读状态；tabs 用于当前页面、翻译状态和缓存范围；scripting 与 webNavigation 支持扩展自带的页面与编辑桥接脚本、内嵌 frame、导航与规则预览；alarms 清理本地缓存。HTTP/HTTPS 站点权限用于翻译可访问页面和连接用户配置的服务。本地文件翻译还需在 Chrome 扩展详情中开启“允许访问文件网址”。Chrome 和 Edge 的 declarativeNetRequestWithHostAccess 仅为扩展发起的模型服务请求设置 Readomi User-Agent。

这些权限服务于翻译及相关阅读控制，不用于广告、画像或出售个人信息。模型响应作为数据处理，所有可执行扩展代码均随扩展打包，包括编辑器和 YouTube 桥接脚本。导入的站点规则含校验后的配置、选择器和受限制的 CSS；扩展不下载执行远程 JavaScript 或 WebAssembly。

## 数据使用与删除

Readomi 对用户数据的处理遵守 Chrome Web Store User Data Policy，包括 Limited Use 要求。不出售数据，不用于个性化广告。内容与凭证按上述功能所需发送到配置的服务。

可在设置中修改或删除服务、密钥与站点规则。“设置 → 翻译缓存”清空全部译文与摘要缓存；弹窗的清除操作删除当前主机名的网页译文以及当前页面的字幕与摘要，保留已显示译文。在某站点停用扩展会暂停该主机名上的功能，不删除已保存设置或缓存。

卸载会删除浏览器管理的扩展数据；导出或分享的副本仍留在保存或接收位置。删除服务商保留的数据需遵循其流程。主动提交到 GitHub 的信息由 GitHub 处理，并可能公开，请勿附上密钥或私人页面内容。
