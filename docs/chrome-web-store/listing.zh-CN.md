# Readomi 简体中文商店文案

以下字段可分别复制到简体中文商店介绍。图片上传使用 `assets/zh-CN/`，推荐类别为 Productivity 下与阅读或语言相关的类别，以后台实际选项为准。

## 名称

Readomi

## 短描述

帮助你读懂网页，支持页面、段落与字幕翻译。

短描述与 `src/locales/zh-CN.yml` 的 `extDescription` 一致；名称与简短说明由提交包的本地化 manifest 提供。

## 详细描述

Readomi 是一个以翻译为核心的浏览器阅读助手。译文直接融入正在读的网页，支持双语对照或仅译文，让你顺着原来的页面继续读。

【围绕阅读的翻译】
• 整页翻译优先处理可见内容，保留页面布局。
• 在双语对照与仅译文之间切换，再次触发翻译可恢复原文。
• 可开启段落悬停翻译，把鼠标放在段落上，再按配置的触发键。
• 可翻译 YouTube 已开启的字幕和 HTML5 字幕轨道，并调整字幕字号、样式与位置。
• 在输入框连续按三次空格，原位翻译草稿；成功后不自动提交。
• 可开启英文词首加粗，按自己的习惯阅读原文。

【自己选择翻译服务】
支持 OpenAI、Anthropic、Gemini、DeepSeek、兼容 API 与本地模型。手动配置服务并测试保存，或复制设置说明，让你的 coding agent 验证服务后生成配置。可添加、排序多个服务，并在弹窗中切换；已显示译文会保留，新请求使用所选服务。支持获取模型列表、自定义提示词和请求参数。

【按自己的习惯使用】
设置主要语言与第二语言：其他语言译为主要语言，主要语言内容可译为第二语言或保持原文。可调整快捷键、网页译文样式，以及亮色、暗色和四种主题色。可在当前页面单独切换字幕，在指定站点停用扩展；使用内置站点规则或通过 agent 预览并保存定制规则。弹窗可清除当前域名的网页译文与当前页面的字幕、摘要缓存，设置页可清空全部翻译缓存。界面支持包括简体中文和英语在内的多种语言，配置可在本地导入与导出。

【使用前需要知道】
Readomi 没有内置托管翻译服务。首次使用需要自行配置模型服务和 API Key，或可用的本地模型接口。第三方服务可能收取费用，并按其自身政策处理请求；Readomi 不提供额度，也不保证所有自定义接口都兼容。

网页、段落、输入框和已有字幕文本会直接发送到你配置的服务。源语言在翻译请求内判断，不会在打开页面时单独请求语言识别；已开启整页翻译后，新内容与同站点导航仍可能继续发起请求。网页翻译会附加可用的页面标题；开启“结合文章上下文”后，还会发送标题与正文前 2,000 个字符生成摘要。自定义提示词也可包含页面描述或截断正文。输入框与字幕翻译不附加网页背景。请阅读隐私政策和所选服务的政策。

设置、密钥和缓存保存在浏览器本地，不会同步到开发者服务器。Readomi 没有账号、分析统计或遥测。完整配置备份包含 API Key、自定义请求头和请求体；服务配置及 agent 设置说明仅遮蔽专门的 API Key 字段，请妥善保管。

悬停翻译和视频字幕翻译默认关闭；输入框翻译默认开启，可在设置中关闭。视频翻译依赖已有字幕，不包含无字幕视频的语音识别。Chrome 内部页面及其他受浏览器限制的页面无法注入翻译界面。

【项目来源与定制理念】
Readomi 修改自 Xuanwo/jiandao 和 mengxi-ream/read-frog，主要移除了 Read Frog 的悬浮工具栏、朗读、自定义 AI 动作、托管账号、配置同步和统计等功能，并在 jiandao 的基础上添加了作者需要的功能。我希望尽可能保持功能简洁，并提供本地化的使用体验，因此基于个人体验进行了定制。

另一个重要原因是，我认为在 AI 时代，翻译这类基础能力人人都可以按需定制。如果你喜欢 Readomi 目前提供的精简功能，欢迎使用；如果你需要 Readomi 有意从 Read Frog 中移除的功能，可以使用 Read Frog 或其他同类产品。

感谢 Read Frog 和 jiandao 的开源贡献。没有它们，就没有 Readomi。
