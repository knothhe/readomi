# 弹窗：在此网站禁用扩展

弹窗实现遵循本版设计。以 `Popup-Design-A*.html` 和
`Popup-Site-*.html` 的本轮状态为准；`Popup-Site-Disable-Review.html`
提供正常、禁用与深色禁用的并排对照。

## 排列与反馈

- 网站开关直接接在视频字幕后，属于同一个功能列表；四行均为 42px，
  标签均为 13px，不增加分隔线、独立卡片或额外上间距。
- 默认关闭表示扩展仍可使用，开关可点击。正常关闭轨道使用较深的暖灰色、
  明亮滑块和描边；真正不可操作时使用浅轨道和暗滑块。保留 hover 与焦点反馈。
- 开关标签与开关均可点击；开关周围有扩大后的点击区域。键盘可聚焦、
  用空格切换，读屏读取 switch 状态、当前域名与影响范围。
- 正常与禁用状态均不显示域名或禁用提示，不为提示预留空行。
  开关和其他功能的可用状态直接体现效果，切换前后弹窗高度一致。
  完整域名与影响范围仅保留在悬停提示和读屏说明里。
  仅保存失败和页面不可用时显示现有状态文案，保存期间不显示提示或预留空行。

## 禁用后的功能

- 网页文字、悬停翻译与视频字幕保留原位置、快捷键和原有开关选择。
  控件真正 disabled，不能点击或通过键盘操作；文字、按钮与轨道置灰。
  不通过把开关改成关闭来表示暂停，避免误认为原有设置被清空。
- 网站开关保持正常文字与强调色，可立即关闭它来恢复使用。
- 保留语言、服务选择、译文质量帮助与设置入口，仍可调整全局配置。
  清理当前网站缓存、英文词首加粗、用 Agent 适配此网站保留但置灰。
  帮助折叠区仍可展开；原来已展开的状态保持展开。
- 重新启用后按原有配置恢复可用状态，不额外自动发起整页翻译。
- 当前页字幕选择保存在会话中，网站暂停期间仍可读取；关闭并重新打开弹窗也保持原选择。
  恢复网站后使用该选择，不能退回全局默认。刷新、换页或命中字幕排除规则仍清除当前页选择。
- 已翻译页面额外显示进度与重译操作。网站保存、禁用与恢复期间保留这块区域的原高度，
  隐藏过期进度与操作，以免网站开关移动；本次弹窗中主动点按网页翻译按钮后解除占位，
  关闭弹窗或换页也解除。三种实际状态分别见 `Popup-Site-Translated.html`、
  `Popup-Site-Translated-Disabled.html`、`Popup-Site-Translated-Resumed.html`；字幕示例使用
  与全局开启默认不同的当前页关闭选择。

## 保存与异常

- 保存期间只锁定网站开关，不显示保存提示；功能保持保存前的状态。
  通过 aria-busy 表达处理中，保存期间和保存成功后的弹窗高度不变。
  禁用保存中仍显示可用功能，重新启用保存中仍显示置灰功能。
- 保存成功才恢复功能的可用状态，不隐藏行、不移动恢复入口。
  关闭网站禁用开关后，字幕状态可能尚未同步：保留原有字幕选择和置灰状态，
  收到当前页可用状态后再恢复字幕开关；不显示短暂的“当前页面无法切换视频字幕。”提示。
  真实命中字幕排除规则或不支持的页面仍显示不可用说明。
  此过渡状态见 `Popup-Site-Resuming.html`。
- 保存失败保留保存前状态，显示“保存失败，请重试。”，开关恢复可点击。
  首次禁用失败见 `Popup-Site-Failed.html`；重新启用失败见
  `Popup-Site-Enabling-Failed.html`。
- 只有当前页面没有可用网站域名，或正在保存时，网站开关本身才不可操作。
  不可用页面保留功能列表，并解释“当前页面不可用”。

## 文案与实现

状态文案沿用 `src/locales/zh-CN.yml` 的 `popup.siteDisable`，本轮不修改 locale。
实现须同步 DOM disabled、键盘行为、读屏描述与保存失败回滚；
设计中的按钮用于展示真实状态，HTML 画板不执行扩展配置写入。

## 已采用的动效

采用 `Popup-Motion-A.html` 的叠层淡化，速度保持当前设计稿：功能行与底部工具组的旧视觉层在 720 ms 内淡出，开关滑动在 640 ms 内完成。保存过程中与保存失败时不触发可用状态淡化；保存成功后才切换。字幕恢复淡化等待实际可用状态同步。功能始终保留、行高固定；视觉层不能交互且对读屏隐藏。减少动态效果时直接切换。细节见 `popup-motion-flow.md`。
