jq -n --arg k "$KEY" '{ type: "deepseek", apiKey: $k, model: "deepseek-flash", … }' | pbcopy
已验证并复制。到设置 → 翻译服务，选“添加服务”；修改已有服务时，从该服务菜单进入“修改”。粘贴后点“检查并添加”或“保存修改”。
1 · 用户
复制说明交给 agent
添加服务或从目标服务菜单进入“修改”，复制说明。添加从空配置开始；修改只带该服务的配置，Key 已脱敏。
2 · agent
问清服务，用 Key 验证到通过
问用哪家、Key 在哪。按指南里的请求模板发请求，被拒就换模型或去掉 body 字段再试。
3 · agent
配置进剪贴板
只含翻译服务本身的字段。用 jq 生成 JSON 写入剪贴板，Key 不出现在 agent 的输出里。不走 URL，因为浏览器历史会记下完整地址。
4 · 用户 · Readomi
粘贴，检查后保存
在独立编辑页粘贴并核对预览，点“检查并添加”或“保存修改”。检查成功后保存并清空剪贴板；失败保留输入和原配置。
同地址可以添加不同模型或账号。添加默认不切换，勾选“添加后使用此服务”才切换；首次配置自动成为当前服务。修改只更新目标服务，保留当前服务选择和已有译文。
{ "type": "deepseek", "apiKey": "sk-…a9f2", "model": "deepseek-flash", "body": { "thinking": { "type": "disabled" } } }
type：openai · anthropic · gemini · deepseek · openai-compatible（需 baseURL）。可选：api（openai-responses · openai-chat · anthropic · gemini）、name、baseURL、headers、body、temperature。语言、显示方式和提示词不在这份配置里。
修改时保留脱敏 Key，只有服务类型和地址未变才沿用目标服务密钥；添加服务、换 Key、改类型或地址时需提供完整 Key。

也可以在添加或修改页选择“手动配置”，或从“备份”导入本插件配置。
