# 弹窗状态过渡

交互预览：[Popup-Motion-A.html](Popup-Motion-A.html)。沿用当前紧凑列表、字号、间距与浅色 / 深色配色，使用仓库内的 Motion，不发起外部请求。

站点可用状态切换采用原位叠层淡化：旧视觉层 720 ms 淡出，开关 640 ms 滑动 14 px，时间曲线为 `[.22, 1, .36, 1]`。首次打开不播放动画；快速反向切换取消旧动画并从当前视觉值继续。减少动态效果时直接切换。

保存期间站点开关锁定，保留先前的功能状态。保存成功后才切换可用状态；失败保留原配置并显示失败提示。字幕在页面同步完成后再进入恢复淡化。

动画保持行高、布局、主控件身份和键盘焦点。快照不可点击、不可聚焦并对读屏隐藏，完成后清理临时样式。预览页控件只操作当前页面内存，不读写扩展设置。
