# 弹窗动效提案（A 已采用）

交互对比：`Popup-Motion-Review.html`。单版原型：`Popup-Motion-A.html`、`Popup-Motion-B.html`、`Popup-Motion-C.html`。沿用当前已采用的紧凑列表、字号、间距与浅色 / 深色配色。原型使用仓库已有的本地 Motion 13.5.1，不发起外部请求。

| 方案 | 状态切换 | 时间 | 感受 |
| --- | --- | --- | --- |
| A · 叠层淡化（已采用） | 新状态在原位呈现，旧状态的不可交互视觉层淡出；不会把整行淡成空白 | 720 ms（原速 180 ms） | 最接近淡入淡出 |
| B · 柔和过渡（对照） | 标签颜色、按钮 / 开关底色与透明度同步插值 | 800 ms（原速 200 ms） | 连续、克制，适合频繁切换 |
| C · 轻错峰 | 同 B 的颜色过渡；网页、悬停、字幕、底部依次开始，每组延迟 100 ms（原速 25 ms） | 660 ms + 300 ms（原速 165 ms + 75 ms） | 节奏稍明显，仍不移动文字 |

三个方案的站点开关滑块默认在 640 ms 内（原速 160 ms）平滑移动 14 px，不使用弹簧回弹。时间曲线为 `[.22, 1, .36, 1]`，起步直接，缓慢收尾。点按悬停 / 字幕自己的开关也可体验滑块。

## 节奏调整

用户反馈 A / B 差异不明显、四倍慢放更舒服。A 的视觉叠层混合与 B 的直接颜色插值，在同位置、同文本、同终态的纯色控件上确实近似，不再把它们强调成显著不同的视觉风格。用户最终选择 A 的自然叠层淡化，按当前设计稿速度实施：旧视觉层 720 ms 淡出，开关 640 ms 滑动。B / C 保留用于对照。预览的「原速对照」只切换时长，标签显示当前实际时间，不影响状态与选择。

## 两个方向

- 在此网站禁用：功能立即不可交互，再过渡到当前的置灰样式；原本开启的悬停 / 字幕开关保持开启位置。
- 恢复使用：在原位恢复当前的正常样式，保留原先选择；字幕同步沿用已采用的恢复状态设计，不新增临时不可用提示。
- 这轮只演示可用状态之间的视觉过渡。实际保存仍沿用现有行为：保存期间锁定站点开关，保留之前的功能状态；完成后才进入目标可用状态。动画不替代保存完成或字幕同步判断。
- 动画不改变行高、内容高度、文本、DOM 主控件身份或键盘焦点。保留当前功能，没有新增“正在保存”或成功提示；失败仍沿用现有失败画板。
- 快速反向切换从当前视觉值继续，旧动画取消；旧快照不可点击、不可聚焦、对读屏隐藏。收尾清除临时动画样式，最终状态由 CSS 与原生 disabled 决定。
- 遵循 `prefers-reduced-motion: reduce`，状态直接切换。预览页可手动模拟减少动态效果；默认采用原四倍慢放的舒缓节奏，并提供「原速对照」与深色对比。

实现以每个功能行与底部工具组为独立视觉层；字幕在远端同步完成后才开始自身的恢复淡化。实际交互控件保留原 DOM，立即遵循保存后的可用状态；视觉层对读屏隐藏且不能接收指针或键盘输入。首次打开弹窗不播放状态淡化，关闭弹窗或切换减少动态效果时清理动画。

打开比较页后点击「同时禁用 / 同时恢复」；也可点击各弹窗的站点开关单独比较。所有演示控件只在设计页中操作，不读写扩展设置。
