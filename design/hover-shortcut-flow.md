# 悬停翻译 · 网站字符键冲突

本次修复使用通用事件规则；不读取域名，也不增加站点设置或产品文案。

## 阅读时接管触发键

前提：悬停翻译已启用，触发方式为反引号，鼠标指向仍在页面中的可翻译正文，按下反引号。
按下时同步识别当前 hover 目标，允许两类正文：当前 include 范围内有内容、可见的段落；
或已声明的 `translationGroups`，且该组至少有一项允许翻译、非空、可见的 source 正文。
组的有效性按 `sourceSelectors` 指定的真实正文判断，不要求 owner 自身命中 include，
也不能为了认领按键把 owner 整体加入 include 或整块提取其文本。
排除区域、隐藏内容、可编辑内容、空来源及 `sourceSelectors: []` 停止的组不认领按键。
组存在但没有允许的 source 正文时，保持网站原有键盘处理。
仅译文模式由扩展隐藏了原文时，可见的该组译文仍可认领按键，用于再次触发恢复原文。
事件发生时，焦点和事件来源都不属于输入框、可编辑区域或输入法组合过程。

在捕获阶段认领这一次有效按键，阻止默认输入和网站继续处理该键。
网站因此不会因反引号而聚焦消息输入框，也不会在输入框插入字符。
点按松开或按住 500 毫秒仍沿用现有翻译时机，同一次按键只触发一次。
长按期间的重复按键和最终松开事件也属于已认领的这次操作，不传给网站。
即使移动鼠标或拖动取消本次翻译，已认领的反引号仍由扩展接管到松开为止。

`Page-Hover.html` 呈现结果：悬停消息显示译文，消息输入框仍为空且没有焦点。
等待与流式输出继续使用现有画板和原位译文，不新增提示、弹层或控件。

Reddit 首页普通 `shreddit-post` 与广告 `shreddit-ad-post` 使用相同的组认领契约。
鼠标命中标题、正文或对应覆盖链接时，均可找到所属 card group；
广告的覆盖入口为直属 `delegated-link[slot="full-post-link"]`，正文来源只选直属 `div[slot="title"]`
和可选 `delegated-link[slot="text-body"] > .md`。普通帖仍只选标题与摘录/正文。
每帖一次请求，沿用同一竖线译文容器，不把任一种 owner 整体加入 include 或提取。
媒体、投票、分享、品牌/用户名、`Ad` 标识与 `Learn More` CTA 都不是正文来源；
Ad 与 CTA 保持原文，CTA 保持媒体后的原位置和链接行为。
对应既有 `Page-Reddit-Reading-Waiting.html`、`Page-Reddit-Reading-Streaming.html`
和 `Page-Reddit-Reading-Ready.html`；按键认领不改变它们原文后、媒体前的插入位置。

## 已在输入时保留打字

输入框或可编辑区域已有焦点时，不认领按键，不阻止网站收到字符，也不触发悬停翻译。
事件来源位于编辑区或输入法正在组合时同样保留输入。

`Page-Hover.html` 呈现结果：鼠标仍可停在消息正文上，输入框已有焦点，反引号正常输入，正文不产生译文。

## 不认领的按键

悬停翻译关闭、反引号未配置为触发键、鼠标下既无有效 include 段落也无具备允许 source 的已声明组、组合键或输入法组合时，保持网站原有键盘处理。
Option / Alt、Control、Shift 沿用原来的事件传递，避免占用网站组合键。
现有拖动取消、再次触发恢复原文及鼠标长按行为保持不变。

## 多段连续触发

悬停 A 段触发翻译后，可以立即移动到 B 段再次点按或长按快捷键；鼠标长按同样适用。
每次有效触发接受当时的段落，各段保留自己的等待点、流式译文与完成结果；A 不因 B 启动而取消。
请求调度沿用后台服务队列。连续触发即使遇到延迟的配置读取，也不能互相覆盖。

- `Hover-Multi-Paragraph-Waiting.html`：两段同时等待，第三段保持原文。
- `Hover-Multi-Paragraph-Streaming.html`：两段独立显示流式译文。
- `Hover-Multi-Paragraph-Mixed.html`：A 已完成，B 仍等待；A 的完成不影响 B。
- `Hover-Multi-Paragraph-Only-Streaming.html`：仅译文模式两段分别在原位输出。

同一段落（包括其行内子元素和所属 translation group）仍在等待、输出或提交时，重复触发不发送新请求，
也不取消该段；覆盖正在翻译段落的祖先/子段落同样不启动重叠任务。
有效正文上的反引号在这些状态下仍接管到松开，避免网站把它送入输入框。
完成后再次触发继续恢复原文。单段的取消按钮只取消该段；Escape 取消所有未完成任务，保留已完成结果。
关闭悬停翻译、相关配置改变、页面导航及内容脚本销毁取消所有未完成任务；迟到结果不回写。
