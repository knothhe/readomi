Readomi · 配置翻译服务

在设置页选择手动配置，或复制给 agent 的说明。配置只描述翻译服务；主题色、语言和显示方式保留为用户设置。

点击 Readomi 工具栏图标，打开设置 → 翻译服务。新配置点“添加服务”；修改已有配置时，从目标服务菜单进入“修改”。粘贴配置后点“检查并添加”或“保存修改”。不要把含密钥的配置放进 URL。

同地址可以保存不同模型或账号。添加默认不切换，勾选“添加后使用此服务”才切换；首次配置自动成为当前服务。修改保留当前服务选择；只有服务类型和地址未变，脱敏 Key 才沿用目标服务密钥。
