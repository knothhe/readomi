# 网页译文缓存

网页译文按当前标签页的域名共享。域名不包含协议、端口、路径、参数或
hash；不同子域名分别缓存，本地文件继续按完整 URL 隔离。

同一域名、同一网页翻译入口下，原文、翻译语言、翻译服务和生效的翻译规则相同，就复用已有
译文。页面标题、描述、正文上下文和摘要的变化不另建网页译文缓存，即使
自定义提示词使用这些字段也如此。未选中的提示词和提示词名称不影响复用。

例如，一条完整的 X 推文在首页和详情页显示相同原文时，页面标题不同不应
触发第二次翻译。首页原文被截断时，截断文本与详情页完整原文分别缓存。

首次翻译仍使用当前页面的上下文。后续命中缓存时沿用已有译文；读者需要
重新生成时，可以使用「重新翻译此页」或「清理翻译缓存」。清理覆盖当前
域名的网页译文，以及当前页的字幕和摘要缓存，保留已有显示内容。

字幕、输入翻译和摘要继续按页面隔离；字幕和输入翻译不借用网页上下文。
