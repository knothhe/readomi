Readomi 隐私政策中文译文

更新日期：2026 年 10 月 2 日。本译文对应仓库根目录的 `PRIVACY.md`，用于帮助中文用户理解；商店隐私政策链接指向正式英文政策。若行为发生变化，两份政策应一起更新。

Readomi 是支持网页、段落和已有视频字幕翻译的浏览器阅读助手。它没有开发者运营的翻译服务器、账号系统、云同步、分析统计或遥测。开发者不会通过扩展收到你的网页内容、API Key 或浏览历史。

发送到你配置的服务的数据

请求从浏览器直接发送至你配置的模型服务或兼容接口。支持的服务包括 OpenAI、Anthropic、Google Gemini、DeepSeek，以及兼容网关和本地模型。接收方是配置中显示的服务端点；网关可能按其条款转发请求给上游服务。

翻译请求包含需要处理的网页、段落或已有字幕文本、提示词和模型参数。网页翻译会自动包含可用的网页标题。开启“使用网页摘要”后，Readomi 还会发送标题和提取的正文前 2,000 个字符，生成辅助段落翻译的摘要。默认和自定义提示词都会附加可用的标题和启用后的摘要；自定义提示词还可通过网页变量加入描述或提取的正文。字幕翻译使用共用的翻译规则，不包含网页背景，也不生成整段视频摘要。没有值的背景信息会省略。

配置服务后，Readomi 可能在页面打开或变化时发送短文本样本识别源语言，即使你尚未点击翻译。当前语言识别请求最多使用 500 个清理后的字符，来自页面标题和页面文本样本。

测试服务会发送简短测试请求；获取模型会查询你配置的服务。请求附带你为该服务输入的 API Key 和可选自定义认证头。服务商也能收到 IP 地址等常规网络信息。

服务商按其隐私政策与条款处理请求。Readomi 开发者不控制服务商的数据保留、训练或访问规则。处理敏感内容前请阅读所选服务的政策。官方服务地址使用 HTTPS；自定义地址可以使用 HTTP，包括本地模型地址。远程服务应使用 HTTPS。

保存在浏览器中的数据

Readomi 在扩展本地存储中保存设置、服务地址、API Key、自定义请求头、提示词、语言、外观和功能开关。API Key 保存在浏览器扩展存储中，不是单独加密的密钥保险库。

译文与文章摘要缓存在本地 IndexedDB。超过七天的条目会进入清理范围；浏览器可运行扩展时，约每天检查一次。关闭或挂起浏览器可能延迟清理。

临时会话存储保存各标签页的翻译状态、站点 origin 与检测语言，以显示正确状态并在同站点恢复翻译。Readomi 不建立浏览历史记录，也不把这些状态发送给开发者。设置与密钥保留到你修改它们或卸载扩展；不会跨设备同步。

你主动创建的副本

导出配置备份会生成包含设置、API Key 和自定义请求头的本地 JSON 文件。卸载扩展不会删除这些导出文件；请自行保管并在不再需要时单独删除。

配置流程可以把服务配置或 agent 说明复制到剪贴板。服务配置导出会隐藏已保存 API Key 的完整值。如果你主动把说明或密钥交给 coding agent 或其他应用，对方会按其条款处理你分享的内容。Readomi 不会自动把配置发送给 agent。

权限与用途

storage 用于保存配置与阅读状态；tabs 用于找到当前阅读标签页并更新图标和弹窗状态；scripting 与 webNavigation 支持页面 frame 内翻译及导航状态处理；alarms 清理本地缓存；HTTP 与 HTTPS 站点访问权限用于插入译文和连接用户配置的服务。

这些权限服务于“通过翻译及相关阅读控制帮助用户阅读网页”这一单一用途，不用于广告、画像或出售个人信息。模型返回内容作为数据处理；扩展不会加载远程 JavaScript 或 WebAssembly 作为自身执行代码。

数据使用与删除

Readomi 对用户数据的处理遵守 Chrome Web Store User Data Policy，包括 Limited Use 要求。不出售用户数据，不用于个性化广告。用户内容与凭证仅按上述阅读功能所需传输给配置的服务。

你可以在设置中修改已保存配置或密钥。卸载扩展会删除浏览器管理的扩展本地数据；已导出或主动分享的副本仍保留在其保存或接收位置。删除模型服务保留的数据需遵循该服务的流程。

如果你主动在 GitHub 提交问题，所提交信息由 GitHub 处理，并可能公开；请不要附上密钥或私人网页内容。
