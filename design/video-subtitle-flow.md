# 视频字幕当前设计

设置入口：[Settings-Subtitle-Size-Default.html](Settings-Subtitle-Size-Default.html)。播放器入口：[Video-Player-Appearance.html](Video-Player-Appearance.html)。以 `src/types/config/subtitle-style.ts`、`src/utils/subtitles/appearance.ts`、设置页 `features/` 和 `src/locales/zh-CN.yml` 为本次对齐依据。

## 外观与预览

- 当前可选预设为「素白」「暖金」「墨笺」。三者大小均为 100%、原文比例均为 100%。素白使用默认字体、白字、无背景；暖金使用宋体、#FFE0A0、无背景；墨笺使用默认字体、#F9FAFB、78% 深色底。选择预设重置其大小、原文比例、字体、颜色和背景，保留位置。
- 「字幕大小」100% 对应视频实际显示区域短边的 3.5%，不计 contain / scale-down 黑边。输入范围由短边 1.25%～25% 换算为约 35.71%～714.29%；滑块可达整步范围 40%～710%，步长 5%；数字输入保留精确值。常用大小为 80% / 100% / 125% / 150%。
- 原文相对字号范围 50%～150%，步长 5%，默认 1:1；快捷选项为 85% / 1:1 / 125%。仅译文模式下禁用该控件并保留已保存值。无效输入不保存；保存失败保留预览和草稿，提供重试。
- 译文字体和颜色独立可调；颜色支持柔白、暖金、浅青与六位十六进制自定义值。背景深度 0% 表示无背景；位置有顶部、居中、底部与复位，支持拖动和方向键精调。
- 预览参考画面短边 720 px：横版 1280×720、竖版 720×1280、正方形 720×720。画面与字幕一起缩放；字幕最大宽度 80%。默认短句为「Let’s begin our journey. / 让我们开始这段旅程。」；长句用于观察换行。示例与画面比例只影响预览。溢出保留真实大小并显示建议减小字号或原文比例的提示。
- compact / study / cinema 仅作为已保存配置的兼容值，当前预设菜单不提供它们。导入旧固定字号或旧宽边比例时走现有迁移规则，不把旧样式画板当作新默认值。

## 页面状态与播放器

弹窗、默认 Option / Alt + V 快捷键和播放器开关操作同一个当前页面值。设置页「默认开启视频字幕翻译」决定新页面默认值；手动切换只影响当前页面。站点禁用和视频排除优先，无法通过这些入口绕过。

YouTube、youtube-nocookie、X、Twitter 在可用原生工具栏右侧显示图标与独立开关。点击图标打开约 240 px 的菜单，包含三种预设、大小、背景深度、译文颜色及字幕位置复位。打开菜单和调整外观不自动开启翻译。保存失败显示「保存失败，请重试。」，沿用最近保存的播放器外观。

入口与菜单跟随原生工具栏显隐；全屏菜单保留在全屏元素内。没有工具栏或空间不足时隐藏整个入口。Bilibili 和其他通用 HTML5 播放器不显示 Readomi 工具栏，但存在真实字幕轨道时仍可翻译。

有时间轴时提前准备字幕；当前句尚未就绪显示「正在提前翻译字幕…」。只有当前可见字幕时显示「字幕翻译中…」。迟到结果不能配到后面的原文；进度、视频或语言变化后优先处理新位置。字幕空档、广告和视频结束隐藏字幕框，不自动暂停视频。

## 排除与错误

「默认开启视频字幕翻译」与网站排除管理分开。排除支持域名、网址通配符和正则表达式，保留空状态、无效规则、重复规则和保存失败画板。添加成功才清空输入；失败保留类型、输入与已保存列表。

网站级禁用沿用弹窗「在此网站禁用扩展」，同时停止网页、悬停、输入和字幕翻译，保留全局配置。恢复后网页翻译需手动启动，字幕回到默认规则。
